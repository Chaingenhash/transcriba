# Bundled fonts

Liberation Serif, SIL Open Font License 1.1. Bundled so PDF output is identical
on Linux and Windows, and so glyphs outside Windows-1252 render correctly.
`genpdf::fonts::from_files` requires all four variants present.

The full license text and copyright notices are in [`OFL.txt`](./OFL.txt),
copied verbatim from the `ttf-liberation` package (Digitized data copyright
2010 Google Corporation; copyright 2012 Red Hat, Inc.), as required by
OFL 1.1 section 2 to accompany each copy of the fonts.
